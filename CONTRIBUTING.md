# Contribution Rules

1. Yalnızca AVAILABLE durumundaki Issue'lar üzerinde çalışılır.

2. Bir Issue için tek aktif contribution kabul edilir.

3. Issue scope'u dışına çıkılmaz.

4. Repository fork edilir.

5. Development kendi fork'undaki branch üzerinde yapılır.

6. Branch isminde Issue numarası bulunur.

7. Pull Request upstream repository'ye gönderilir.

8. PR açıklamasında ilgili Issue bağlanır.

9. Review sonucu CHANGES REQUIRED ise aynı branch üzerinden revision yapılır.

10. Upstream main branch'e doğrudan push yapılmaz.
